# گزارش کنترل نسخه نمایشی Endura Battery

- کد JavaScript همه ماژول‌ها با دستور `node --check` بررسی شد.
- ۲۱ مسیر اصلی فرانت‌اند از جمله خانه، چهار دسته، PDP، سبد، Checkout، پیگیری سفارش، حساب مشتری، پنل عامل و ادمین در Chromium Headless با تست ماژول‌های باندل‌شده بررسی شدند.
- گردش خرید نمونه: افزودن باتری واقعی کاتالوگ به سبد → وارد کردن اطلاعات تحویل → بررسی شهر و موجودی → انتخاب پرداخت آنلاین آزمایشی → دریافت شناسه سفارش؛ بدون خطای JS اجرا شد.
- عملیات نمونه پنل: افزودن محصول UPS → نمایش در دسته UPS، ویرایش Hero → نمایش در خانه، افزودن خودرو به حساب مشتری، پذیرش سفارش توسط عامل → مراحل آماده‌سازی/اعزام/نصب/تکمیل؛ بدون خطای JS اجرا شد.
- وارد کردن فایل XLSX کاتالوگ فارسی در مرورگر بررسی و انجام شد.
- پیش‌نمایش‌های تصویری دسکتاپ و موبایل در همین پوشه قرار گرفته‌اند.

**محدودیت تست:** تست مرورگری در محیط کنترل‌شده روی import درون‌حافظه‌ای ES Modules انجام شد، نه استقرار عمومی GitHub Pages. تست تراکنش مالی یا ورود به سامانه واقعی انجام نشده است.
