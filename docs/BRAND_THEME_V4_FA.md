# راهنمای هویت بصری و تم Endura Battery — نسخه ۴

## تغییرات این نسخه

تمام صفحات فروشگاه، پنل مدیر و مسیرهای مرتبط از همان CSS مشترک استفاده می‌کنند. پالت از فایل `Endura_Battery_Complete_Brand_Book.zip` که برای پروژه ارائه شد استخراج شده است.

- Nexus Plum: `#1B0B37`؛ زمینه برند و هیرو
- Volt Lime: `#D8FC55`؛ CTA و اکسانت
- Neo Lavender: `#B392FC`؛ خطوط آیکن در تم تاریک
- Soft White: `#F8F6FA`؛ پس‌زمینه تم روشن
- Deep Plum: `#211039`؛ نوشته‌ها در تم روشن
- Royal Violet: `#8056CF`؛ آیکن‌ها و لینک‌ها در تم روشن

لوگوی رسمی Nexus Grid در `assets/brand/endura_full_light.svg` و `endura_full_dark.svg` قرار دارد. نسبت‌ها و فرم اصلی لوگو تغییر نکرده‌اند. فاوآیکن نیز از نماد رسمی برگرفته شده است.

## سوئیچ تم

دکمه روشن/تاریک پایین همه صفحات در فوتر قرار دارد. در بازدید اول اگر انتخابی ذخیره نشده باشد، تنظیم دستگاه خوانده می‌شود (`prefers-color-scheme`). وقتی کاربر سوئیچ را تغییر دهد، انتخابش در `localStorage['endura-theme']` ثبت می‌شود و در بازدیدهای بعدی همان انتخاب نمایش داده خواهد شد. اگر کاربر انتخاب دستی نداشته باشد، تغییر تنظیم سیستم نیز دنبال می‌شود.

برای بازگشت به تشخیص خودکار سیستم، در کنسول همان سایت بنویسید:

```js
localStorage.removeItem('endura-theme'); location.reload();
```

رنگ آیکن‌ها در هر تم از نسخه اختصاصی همان آیکن استفاده می‌کند. فایل‌های `assets/icons/name.svg` مخصوص تم روشن و `assets/icons/name-dark.svg` مخصوص تم تاریک هستند. هر دو از هندسه خطی SVG استفاده می‌کنند.

## تصاویر

- تصویر Hero: `assets/images/hero-nexus-scene.svg` (نسخه برداری با رنگ‌های برند)
- دسته‌های سبک/سنگین/UPS/سولار: `assets/images/category-*.svg`
- fallback تصاویر کالا: `assets/images/placeholder-battery.svg`
- لوگو: SVGهای رسمی و دست‌نخورده برندبوک در `assets/brand/`

برچسب باتری داخل تصویر Hero یک **تصویرسازی مفهومی** است، نه تصویر تجاری تأییدشده از یک SKU. عکس‌های محصول یا کمپین که مدیر از Supabase Storage بارگذاری کرده است جایگزین نمی‌شوند. برای نمایش محتوای واقعی حتماً از پنل مدیریت عکس محصول را بارگذاری و صحت آن را بررسی کنید.

## فونت

CSS همچنان دارای `@font-face` برای IRANSans فارسی و import برای Open Sans انگلیسی است. برای استفاده از فونت فارسی دارای مجوز خودتان، فایل `IRANSans.ttf` را مطابق مسیر `assets/fonts/IRANSans.ttf` داخل پروژه خود اضافه کنید. فایل فونت در بسته توزیع نشده است. فونت Open Sans با درخواست از Google Fonts بارگیری می‌شود؛ در صورت لزوم استفاده کاملاً آفلاین، باید فایل دارای مجوز آن را نیز به‌صورت مستقل تهیه و میزبانی کنید.

## فعال‌سازی روی Supabase موجود

برای هماهنگ‌شدن سایت با مقادیر پیش‌فرض برند جدید، فایل

`supabase/migrations/20261102000000_endura_brand_identity.sql`

را بعد از Migrationهای قبلی در SQL Editor اجرا کنید. این فایل تنظیمات رنگ را با پالت برند هماهنگ می‌کند و Hero پیش‌فرض قدیمی را تغییر می‌دهد، ولی فایل Hero سفارشی بارگذاری‌شده در Supabase را دست‌نخورده نگه می‌دارد.

سپس کل پروژه را در GitHub آپلود و منتشر کنید. ممکن است لازم شود کش صفحات و CSS در مرورگر را تازه‌سازی کنید (`Ctrl+Shift+R`). در حالت بررسی بدون اتصال زنده از `?preview=1#/` استفاده کنید.

## آزمون‌های پیشنهادی پس از انتشار

1. در مرورگر با تم روشن و بدون مقدار `endura-theme`، سایت باید روشن باز شود.
2. در مرورگر با تم تاریک و بدون مقدار ذخیره‌شده، سایت باید تاریک باز شود.
3. فوتر را باز و سوئیچ را بزنید؛ بدون بارگذاری مجدد صفحه باید تم عوض شود.
4. صفحه را Refresh کنید؛ انتخاب دستی باقی بماند.
5. از صفحه محصول، لیست کالا، صفحه خودرو، حساب مشتری و پنل مدیریت بازدید کنید؛ هدر، لوگو، کارت‌ها و آیکن‌ها باید با تم هماهنگ بمانند.
6. عکس سفارشی Hero که قبلاً مدیر بارگذاری کرده نباید با Migration جدید بازنویسی شود.

## حدود این نسخه

کاتالوگ، محصولات، Auth و CMS بر پایه اتصال قبلی Supabase حفظ شده‌اند. پرداخت بانکی واقعی و API امن پردازش سفارش و تسویه همچنان به توسعه بک‌اند نیاز دارند. تست نحوی کدها و SVGها انجام شده است؛ در محیط ساخت امکان تأیید رندر نهایی با مرورگر خودکار به‌دلیل محدودیت دسترسی مرورگر فراهم نبود.
