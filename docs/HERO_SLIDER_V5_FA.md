# Endura Battery — Hero Slider V5 (راهنمای فارسی)

## چه چیزی داخل این بسته است؟
نسخه کامل قبلی Endura Battery به‌همراه تمام صفحات، کاتالوگ، پنل مدیریت، اتصال Supabase، دارایی‌های برند، فایل‌های SQL، اسلایدر ۶ تصویری و ویرایشگر اسلایدر.

## راه‌اندازی روی GitHub Pages
۱. کل پوشه `endura-battery-site` را در ریشه مخزن GitHub جایگزین کنید (فایل‌های حذف‌شده را هم در صورت نیاز حذف کنید). `index.html` باید در ریشه مخزن باشد.
۲. Commit/Push کنید و در `Settings → Pages` انتشار را مطابق README بررسی کنید.
۳. برای اولین بار `/#/admin/content` را باز کنید، با Supabase Auth وارد شوید و نقش `admin` را داشته باشید.
۴. در بخش «مدیریت اسلایدر صفحه اصلی» اسلایدها را اضافه/حذف/جابجا و برای هر مورد عنوان، توضیح، CTA، تصویر دسکتاپ و تصویر موبایل را تنظیم کنید.
۵. روی «ذخیره همه اسلایدها در Supabase» کلیک کنید. به صفحه اصلی برگردید و دوباره باز کنید.

## اسم تصاویر هیچ محدودیت ثابتی ندارد
- از دکمه **آپلود تصویر** استفاده کنید: هر نام فایلی که دارید آپلود می‌شود؛ مسیر عمومی امن تصویر خودکار در تنظیمات ذخیره می‌شود.
- یا نام ساده فایل مثل `my-photo.webp` وارد کنید؛ در این صورت آن فایل باید در `assets/images/hero-slider/my-photo.webp` واقعاً موجود باشد.
- یا مسیر نسبی GitHub مثل `assets/images/campaign/banner-a.png` وارد کنید.
- یا URL کامل HTTPS تصویری که از قبل در اینترنت عمومی یا Supabase Storage قرار دارد وارد کنید.
- از فرمت PNG / JPG / WebP / AVIF پشتیبانی می‌شود؛ سایز هر فایل آپلودی حداکثر ۸ مگابایت است.
- تصویر موبایل اختیاری است. اگر خالی باشد همان تصویر دسکتاپ با برش واکنش‌گرا استفاده می‌شود.

## چیدمان متن و تصویر
تصاویر در کل Hero با `object-fit:cover` قرار می‌گیرند (بدون کشیدگی) و متن در ناحیه تاریک سمت راست در دسکتاپ نمایش داده می‌شود. در موبایل تصویر همچنان تمام کادر را می‌پوشاند، با گرادیان زیر متن و چیدمان متن در بخش پایینی کادر. برای هر اسلاید گزینه جایگاه سوژه روی چپ، وسط یا راست تعبیه شده.

## جهت دکمه‌ها در RTL
دکمه **اسلاید قبلی** در سمت راست با فلش رو به راست `❯` و دکمه **اسلاید بعدی** در سمت چپ با فلش رو به چپ `❮` نمایش داده می‌شوند. کلیدهای جهت‌دار و سوایپ هم طبق همین منطق کار می‌کنند.

## ذخیره در Supabase
این نسخه از همان کلید `public.site_settings` و فیلد JSON `value.cms.heroSlides` استفاده می‌کند؛ تا زمانی که Migrationهای قبلی و `user_roles` اجرا شده باشند، **SQL جدید لازم نیست**. تغییرات در مرورگر به‌تنهایی ذخیره نمی‌شود. آپلود تصویر در Storage Bucket رسمی قبلی انجام می‌شود.

## اگر در پنل فرم اسلایدر را نمی‌بینید
- صفحه را با Hard Refresh باز کنید (`Ctrl+Shift+R`).
- بررسی کنید `assets/js/hero-slider.js` و `assets/css/hero-slider.css` از آخرین ZIP در GitHub قرار گرفته باشند.
- مسیر صفحه باید `/#/admin/content` باشد، نه بخش تنظیمات عمومی.
- با حساب دارای نقش `admin` در Supabase وارد شوید. 
- برای نمایش تصاویر آپلودشده، Storage Policyها و Bucket تعریف‌شده در Migrationهای قبلی لازمند.

## امنیت و محدودیت
فقط Publishable Key در سایت قرار دارد. بخش ثبت سفارش واقعی و دریافت پول همچنان به بک‌اند امن و درگاه بانکی نیاز دارد. فونت‌های دارای مجوز باید جدا توسط دارنده مجوز در `assets/fonts/IRANSans.ttf` قرار داده شوند.
