# چک‌لیست قبل از فروش واقعی Endura Battery

## امنیت و هویت
- [x] Supabase Auth برای ورود مدیر و RLS کاتالوگ / CMS
- [x] Supabase Storage برای تصویرهای عمومی
- [ ] هویت واقعی اپراتور، مشتری و عاملان + OTP
- [ ] RBAC واقعی سمت سرور، محدودکردن دسترسی عامل و ادمین
- [ ] حفاظت CSRF/XSS و اعتبارسنجی سمت سرور
- [ ] توکن نشست امن، محدودسازی نرخ و ثبت لاگ
- [ ] HTTPS، حفاظت اسرار و پشتیبان‌گیری دیتابیس

## کاتالوگ و محصول
- [ ] تأیید همه ۱۲۴ محصول و دسته خودرویی از نظر کاربرد واقعی
- [ ] تکمیل UPS و سولار از منبع معتبر
- [ ] تأیید قیمت ۵۱ محصول و تعیین وضعیت ۷۳ محصول نیازمند استعلام
- [ ] بازبینی تصاویر نمونه خانواده؛ جایگزینی با تصاویر مدل دقیق با حق استفاده
- [ ] بازبینی گارانتی، CCA، ابعاد و سازگاری

## فروش و پرداخت
- [ ] قرارداد و API درگاه پرداخت آنلاین
- [ ] پرداخت در محل با روش وصول مورد تأیید و تطبیق مالی
- [ ] سیاست استرداد/لغو و بازگشت موجودی و رزرو
- [ ] پیاده‌سازی سبد چندمنبعی یا محدودسازی آن در MVP
- [ ] مالیات، فاکتور، سامانه مؤدیان و مدارک حقوقی
- [ ] انتقال مالکیت باتری از عامل به فروشنده سایت در قرارداد

## شبکه عاملان و خدمات
- [ ] احراز هویت و قرارداد عاملان، تسویه و SLA

- [ ] رزرو موجودی و ظرفیت به‌صورت اتمیک
- [ ] پوشش شهر/محله واقعی و زمان‌های خدمت
- [ ] ثبت سریال، مدرک تحویل/نصب و مسئولیت خدمات
