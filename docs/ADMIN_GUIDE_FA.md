# راهنمای پنل مدیریت Endura Battery (Supabase Edition)

## ورود امن

۱. در Supabase → Authentication → Users حساب ایمیل/رمز بساز.
۲. طبق README نقش `admin` را در `public.user_roles` ثبت کن.
۳. آدرس `/#/admin` را باز کن و با همان ایمیل و رمز وارد شو.
۴. پس از ورود در بالای پنل، ایمیل مدیر، وضعیت ذخیره و گزینه «خروج امن» و «بازخوانی دیتابیس» نشان داده می‌شود.

## ویرایش کاتالوگ

«کاتالوگ و محصولات» → «ویرایش» یا «محصول جدید». نام، برند، دسته (سبک، سنگین، UPS، سولار)، مشخصات، قیمت و وضعیت انتشار را وارد کن. ذخیره در `public.products` انجام می‌شود. اگر قیمت مشخص نیست خالی بگذار تا «نیازمند استعلام» نمایش داده شود.

برای تصویر می‌توانی URL وارد کنی یا تصویر را از دستگاه انتخاب کنی؛ فایل آپلودی مستقیم در Supabase Storage bucket `endura-public` ذخیره می‌شود و آدرسش در جدول محصولات ثبت می‌شود. از تصاویر نمونه خانواده فقط با برچسب دقیق استفاده کن.

## محتوا و CMS

- «محتوا و کمپین» برای عنوان Hero، دکمه، بنر و توضیح دسته‌ها.
- «مقالات» برای ایجاد/ویرایش/حذف مطالب.
- «تنظیمات اصلی» برای نام، تماس، رنگ، متن فوتر و پیام بالای سایت.

داده Hero/فوتر و متن‌های دسته در `site_settings` و مقاله‌ها در `cms_articles` ذخیره می‌شوند.

## واردکردن جدول

در بخش «ورود/خروج جداول»، فایل XLSX/CSV/JSON محصولات را انتخاب کن. داده‌ها پس از اعتبارسنجی به Supabase فرستاده می‌شوند. هنگام ورود داده، از شناسه یکتای محصول (ID/SKU) استفاده کن. پیش از ویرایش گروهی فایل خروجی/بکاپ بگیر.

**هشدار:** بازگرداندن یک فایل کامل JSON روی کل دیتابیس، یا بازنشانی دیتابیس، از صفحه عمومی وب پشتیبانی نمی‌شود. برای بکاپ/Restore رسمی از ابزارهای دیتابیس Supabase استفاده کن.

## محدوده و عاملان

مدیر می‌تواند ردیف‌های `service_zones` و `agents` را ثبت کند. اما موجودی واقعی و سفارش‌های عاملان هنوز نیازمند API و مدل دسترسی عملیاتی هستند. نمایش پنل عامل عمومی در نسخه آنلاین غیرفعال شده است.

## مالی و سفارش

پرداخت و تسویه واقعی **فعال نیست**. تا پیش از پیاده‌سازی Edge Functions یا بک‌اند امن، هیچ مبلغی از مرورگر نباید به‌عنوان پرداخت موفق ثبت شود.

## اگر ذخیره ناموفق شد

پیام خطا را ببین. نقش مدیر و سیاست‌های RLS را کنترل کن. مقدار جدید فقط در صورت دریافت پاسخ موفق از Supabase قطعی است. برای اطمینان از انتشار، روی «بازخوانی دیتابیس» بزن یا صفحه دیگری را Refresh کن.
