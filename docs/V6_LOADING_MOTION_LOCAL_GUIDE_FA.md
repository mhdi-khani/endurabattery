# راهنمای تغییرات Endura V6

## ۱. اصلاح فلش‌های Hero
دکمه «قبلی» سمت راست، دکمه «بعدی» سمت چپ، و نقطه‌ها در پایین وسط هستند؛ روی دسکتاپ و موبایل جداگانه جای‌گذاری شده‌اند. جهت کلیدهای کیبورد و Swipe متناسب با فارسی است.

## ۲. ورود آزمایشی ادمین — فقط لوکال
ترمینال را در پوشه اصلی سایت باز کنید و این دستور را اجرا کنید:

```bash
python -m http.server 8080
```

آدرس: `http://localhost:8080/?localDemo=1#/admin`

نام کاربری: `endura-demo`  
رمز عبور: `EnduraLocal!2026`

این حساب فقط در localhost و با `?localDemo=1` فعال است. ذخیره‌ها فقط در `localStorage` مرورگر هستند و با Supabase تبادل نمی‌شوند. **این اطلاعات ورود، حساب واقعی ادمین نیستند**؛ در محیط آنلاین GitHub Pages باید با Supabase Auth و نقش admin وارد شوید.

## ۳. لودر
لودر از فایل ارسالی `Endura_Loader_01_to_05.html` اقتباس مستقیم شده است: انیمیشن Bloom شماره ۰۱ فقط یک بار اجرا می‌شود و اگر بارگذاری واقعی سایت هنوز تمام نشده باشد، حالت Skeleton شماره ۰۵ نمایش داده می‌شود. پایان بارگذاری با `window.enduraLoader.done()` کنترل می‌شود. صفحه با تایمر ساختگی ۶ ثانیه‌ای تأخیر نمی‌گیرد.

## ۴. موشن
Motion سبک هنگام رندر صفحه و اسکرول سکشن‌ها اجرا می‌شود و تنظیم `prefers-reduced-motion` را رعایت می‌کند. `IntersectionObserver` فقط عناصر دیده‌شده را انیمیت می‌کند.

## ۵. تصاویر
چهار فایل ارسال‌شده در مسیر `assets/images/categories/` به WebP تبدیل شده‌اند: `light.webp`, `heavy.webp`, `ups.webp`, `solar.webp`. کارت‌های دسته‌ها، کارت‌های راهنمای انتخاب و تصویر دسته باتری خودرو از همین فایل‌ها استفاده می‌کنند؛ آیکون‌های کاربردی/مسیری سایت مستقل باقی مانده‌اند.

## ۶. استقرار
محتویات `endura-battery-site/` را در ریشه ریپازیتوری GitHub قرار دهید. هیچ Migration جدیدی لازم نیست. اطلاعات Supabase و داده‌های قبلی تغییر نمی‌کنند. ثبت سفارش و پرداخت بانکی همچنان به بک‌اند امن نیاز دارد.
