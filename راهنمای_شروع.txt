۱) پوشه را در ریشه GitHub repository قرار بده؛ index.html باید در ریشه باشد.
۲) در Supabase SQL Editor: فایل 20261029000000_endura_initial.sql (فقط اگر جداول قبلاً ساخته نشده‌اند)، سپس 20261030000000_live_catalog_cms_hardening.sql اجرا کن.

۵) در GitHub Settings > Pages گزینه GitHub Actions را انتخاب کن.
۶) سایت را باز کن و از /#/admin وارد حساب مدیر شو. با ویرایش محصول و Refresh مرورگر دیگر ذخیره آنلاین را آزمایش کن.
