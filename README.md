# Endura Battery — فروشگاه و پنل مدیریت (نسخه نمایشی قابل اجرا)

یک پروژه **کامل از نظر صفحات و تجربه کاربری** برای فروش باتری خودروهای سبک و سنگین، UPS و سولار؛ طراحی فارسی، راست‌چین، واکنش‌گرا و آماده انتشار استاتیک روی GitHub Pages.

**توجه:** برای جلوگیری از ایندکس زودهنگام فروشگاه دمو، فایل `index.html` دارای `noindex,nofollow` است. پس از راه‌اندازی واقعی و تکمیل الزامات تجاری، این متا را حذف کنید.

## شروع سریع

- **صفحه اصلی:** `index.html` یا `/#/`
- **فروشگاه:** `/#/shop`
- **محصول:** `/#/product/EN-0001`
- **سبد و تسویه:** `/#/cart` و `/#/checkout`
- **حساب مشتری:** `/#/account`
- **پیگیری سفارش:** `/#/tracking`
- **پنل عامل:** `/#/agent`
- **مدیریت مرکزی:** `/#/admin`

### اجرای محلی

بدون نصب Node.js یا وابستگی:

```bash
cd endura-battery-site
python -m http.server 8000
```

در مرورگر `http://localhost:8000` را باز کنید. برای پروژه استاتیک هیچ مرحله build لازم نیست.

### انتشار روی GitHub Pages

1. یک ریپازیتوری جدید ایجاد کنید.
2. **محتویات داخل** پوشه `endura-battery-site` را در ریشه ریپازیتوری آپلود کنید (نه یک پوشه اضافه دور فایل‌ها).
3. تغییرات را روی شاخه `main` قرار دهید.
4. در GitHub: `Settings → Pages → Build and deployment → Source: GitHub Actions` را انتخاب کنید.
5. فایل `.github/workflows/pages.yml` بعد از هر Push، وب‌سایت را منتشر می‌کند.
6. از لینک منتشرشده همه صفحات را با مسیرهای `/#/...` باز کنید. مسیرهای Hash روی GitHub Pages نیز بدون تنظیم redirect کار می‌کنند.

راه جایگزین: `Settings → Pages → Deploy from a branch → main → / (root)`؛ این روش نیز برای پروژه استاتیک قابل استفاده است.

## فونت‌ها

CSS طوری تنظیم شده که متن فارسی با `IRANSans` و حروف لاتین با `Open Sans` نمایش داده شوند.

برای فعال شدن فونت فارسی، **نسخه دارای مجوز خودتان از `IRANSans.ttf` را در پوشه زیر قرار دهید:**

`assets/fonts/IRANSans.ttf`

فایل باینری فونت در این بسته بازتوزیع نشده است. تا زمان افزودن فونت، Tahoma به‌عنوان جایگزین فارسی استفاده می‌شود. Open Sans از Google Fonts بارگذاری می‌شود و جایگزین سیستمی هم دارد.

## ورود به پنل مدیریت

از صفحه اصلی، لینک **پنل مدیریت (دمو)** در فوتر را باز کنید یا مستقیماً به `/#/admin` بروید.

از پنل می‌توانید **در مرورگر فعلی**:

- محصول جدید (شامل UPS و سولار) اضافه کنید، محصول قبلی را ویرایش کنید و قیمت/موجودی را تغییر دهید.
- تصویر محصول یا تصویر Hero آپلود کنید؛ برای تجربه محلی تصاویر فشرده و در مرورگر ذخیره می‌شوند.
- عنوان و متن Hero، CTA و مقاله‌های مجله را ویرایش کنید.
- برند، دسته، تصویر، مشخصات فنی و وضعیت نمایش هر محصول را تغییر دهید.
- شهرهای پوشش و قابلیت ارسال یا نصب را مدیریت کنید.
- عامل محلی اضافه یا غیرفعال کنید، سفارش را به عامل ارجاع دهید.
- وضعیت دریافت وجه در محل را بررسی و به‌صورت آزمایشی تأیید کنید.
- تنظیمات عمومی، رنگ اصلی، شماره تماس و تعرفه‌های پیش‌فرض را ویرایش کنید.
- جدول محصولات را در قالب CSV، JSON یا فایل XLSX با ستون‌های کاتالوگ فارسی وارد کنید.
- از اطلاعات خروجی CSV/JSON و نسخه پشتیبان بگیرید.

**نکته مهم:** نسخه حاضر استاتیک بوده و مدیریت محتوای آن با `localStorage` انجام می‌شود. تغییراتی که در مرورگر خود اعمال می‌کنید برای سایر کاربران سایت قابل مشاهده نیست. برای مدیریت آنلاین و مشترک محتوا باید بک‌اند، پایگاه داده و آپلود فایل روی سرویس ذخیره‌سازی راه‌اندازی شود. این پنل نباید بدون احراز هویت سروری به‌عنوان پنل واقعی مدیریت مورد استفاده قرار بگیرد.

## دو روش پرداخت و وضعیت سفارش

1. **پرداخت آنلاین در لحظه ثبت درخواست:** در نسخه نمایشی، موفقیت پرداخت شبیه‌سازی می‌شود. قبل از این مرحله پوشش شهر، خدمت مجاز، وجود عامل محلی و آخرین موجودی نمایشی بررسی می‌شود. پذیرش نهایی تأمین بعداً انجام خواهد شد.
2. **پرداخت در محل:** سفارش بدون پرداخت اولیه ثبت شده و وضعیت وصول در پنل عامل/مدیریت ثبت می‌شود.

هیچ اتصال به بانک، تراکنش مالی، پیامک، احراز هویت واقعی یا فروش عملیاتی در این ZIP وجود ندارد. پیش از استفاده تجاری باید APIهای سرور، هویت کاربران، درگاه پرداخت، تسویه و قوانین عملیاتی اجرا شوند.

## کاتالوگ

کاتالوگ واردشده از فایل Excel کاربر شامل **۱۲۴ محصول** است؛ **۸۶ محصول در دسته خودروی سبک و ۳۸ محصول در خودروی سنگین** براساس دسته‌بندی مقدماتی ظرفیت (آستانه ۱۲۰ Ah). این طبقه‌بندی **باید توسط مدیر محصول بررسی شود**، چون صرف ظرفیت برای تشخیص کاربرد کافی نیست.

- ۵۱ محصول دارای قیمت ثبت‌شده در فایل هستند و ۷۳ محصول «نیازمند استعلام قیمت» هستند.
- ۵۱ ردیف لینک تصویر دارند، اما اکثر این عکس‌ها تصویر نمونه یک خانواده هستند و به‌صورت اختصاصی با مدل/آمپراژ همان ردیف تأیید نشده‌اند.
- لینک‌های تصویر خارجی اگر در مرورگر بارگذاری نشوند با تصویر جایگزین محلی نمایش داده می‌شوند.
- هیچ محصول واقعی UPS یا سولار در فایل ارسال‌شده نبود؛ بنابراین صفحات این دو دسته فعال هستند، اما محصول ساختگی به آن‌ها اضافه نشده است. از پنل مدیریت می‌توانید محصول آن‌ها را ثبت یا فایل وارد کنید.
- اطلاعات قیمت، گارانتی، سازگاری و موجودی باید پیش از استفاده تجاری بازبینی شوند.

## پیش از راه‌اندازی تجاری

به سند `docs/PRODUCTION_CHECKLIST.md` رجوع کنید. مهم‌ترین موارد: احراز هویت نقش‌محور، پایگاه داده مشترک، سرویس فایل/تصاویر، موجودی چندعاملی، رزرو همزمان موجودی، پرداخت و استرداد واقعی، SMS، محاسبات مالی/مالیاتی، تسویه عاملان، قراردادها، گارانتی، لاگ و مانیتورینگ، بهینه‌سازی تصاویر و ممیزی امنیت.

این نسخه برای بررسی و تأیید کل UI/UX و گردش صفحات مناسب است؛ **جایگزین یک فروشگاه آنلاین تولیدی متصل به بانک و سرور نیست**.
